# Changelog

All notable changes to this project will be documented here.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),

## [Unreleased]

## [1.1.0] - 2026-09-11

### Added

- Sensor-adjusted brightness sync from the active MacBook display.
- Night Shift warmth sync with restoration of the previous monitor preset.
- Automatic pause while the built-in display is inactive, asleep, or lid-closed.

## [1.0.0] - 2026-09-11

### Added

- Native menu-bar UI for capability-driven DDC/CI monitor controls.
- Brightness, contrast, sharpness, audio, color, input, PBP, power, and reset.
- Raw VCP read/write and a read-only 256-code feature explorer.
- Apple Silicon DDC transport and local ad-hoc app packaging.
